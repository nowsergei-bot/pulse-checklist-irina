# Образец существующего раздела английского

Копия экранов, клиентской библиотеки и основного серверного обработчика установленного раздела. Это справочные исходники: они не подключены к сборке и не заменяют действующий раздел. Импорты сохраняют прежнюю структуру и требуют зависимостей ядра; использовать их как пример, а не как самостоятельный модуль. Правила доступа по персональным спискам из ядра не копируются. Новая среда получает пользователя через доверенный шлюз, а данные — только из pulse_read.
