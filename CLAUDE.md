# Claude: чек-лист Пульса для Ирины Костюкович

Репозиторий: https://github.com/nowsergei-bot/pulse-checklist-irina
Рабочая ветка: `codex/checklist-irina`. Владелец: `nowsergei-bot`.

## Начало работы

Прочитай AGENTS.md, README.md и isolation-manifest.json. Работай только над разделом чек-листа посещения урока: форма, отчёт, аналитика, карточки педагогов, PDF, его расчёты и обработчики. Английская аналитика и остальные разделы Пульса не входят в задачу.

Если репозиторий уже открыт через интеграцию Claude с GitHub, выбери ветку codex/checklist-irina. Для локального Claude Code:

```sh
git clone --branch codex/checklist-irina https://github.com/nowsergei-bot/pulse-checklist-irina.git
cd pulse-checklist-irina
npm ci --prefix frontend
npm run dev --prefix frontend
```

Открой http://127.0.0.1:5173. Стартовый экран — отчёт с демонстрационным ответом; нет подключения к рабочим данным. Для просмотра других экранов добавляй отдельные синтетические сценарии после согласования новых файлов. Не подключай рабочие API, БД или секреты.

## Разрешённые изменения

Точные разрешённые пути перечислены в `editable` манифеста. Основные области: frontend/src/pages/visitChecklist*, frontend/src/pages/LessonVisitChecklist*, frontend/src/lib/lessonVisitChecklist, компоненты и API чек-листа, backend-файлы чек-листа и его миграции. Название папки само по себе не даёт права менять любой новый файл. `context` — вспомогательные исходники, их не редактировать. Не менять манифест, защитные скрипты и CI. Новые пути или общие зависимости требуют владельца.

Сохраняй формулы подсчёта, исходные ответы и правила доступа, если Ирина явно не поставила задачу изменить их. Не выдумывай рабочие данные. Если задача затрагивает общую навигацию, авторизацию или другие модули — опиши необходимое изменение владельцу отдельно.

## Проверка и передача

```sh
npm run build --prefix frontend
npm test --prefix frontend
npm test --prefix backend/functions
python3 scripts/check_scope.py
git add <конкретные разрешённые файлы>
git commit -m "Update checklist: краткое описание"
git push origin codex/checklist-irina
```

Создай PR из codex/checklist-irina в main с описанием изменений и результатами проверок. Не сливай PR самостоятельно. Владелец переносит только проверенный патч в GitLab Пульса, с проверкой конфликтов. Автоматического переноса и деплоя нет.

## Авторизация

Публичное чтение уже доступно. Для записи Ирина должна принять приглашение в этот репозиторий с ролью Write и подключить свой GitHub к Claude (или авторизовать Git в Claude Code). Markdown не предоставляет технические права доступа. Если push запрещён, не использовать чужие токены: сообщить владельцу GitHub-логин Ирины. До приглашения можно работать в собственном форке и предложить PR. Доступ к GitLab, production, БД и облаку для этой задачи не нужен и не выдан.
